### Overview

The following enum values represent the box types that are supported by the ArtPort API:

| ID | Box Type | Description                                 |
|----|----------|---------------------------------------------|
| 1  | Small    | Up to 23in (L) x 19in (H) x 4in (D) - 45lbs |
| 2  | Medium   | Up to 37in (L) x 25in (H) x 4in (D) - 45lbs |
| 3  | Large    | Up to 44in (L) x 34in (H) x 4in (D) - 45lbs |
